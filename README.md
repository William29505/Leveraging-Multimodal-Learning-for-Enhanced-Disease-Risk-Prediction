This project investigates how multimodal patient data can improve the prediction of hospital
mortality using machine learning (ML) and deep learning (DL) methods. Using the Medical
Information Mart for Intensive Care-III (MIMIC-III) dataset, we developed and evaluated six
predictive models (including Random Forest, Decision Tree, Extreme Gradient Boost
(XGBoost), Long Short-Term Memory (LSTM), GRU, and Transformer) on both unimodal
(structured, combining vital sign, laboratory results, and demographic data) and multimodal
(structured + TF-IDF extracted clinical text features) datasets.
